# CREWLOG 內容架構設計文件
**日期：** 2026-03-28
**版本：** v1.0
**負責人：** 賴明宏 Oscar

---

## 核心使命

> 在學生與影視業界之間搭建橋樑，同時讓一般大眾理解劇組日常，讓台灣影視去汙名化。

---

## 目標受眾

| 優先級 | 受眾 | 主要需求 |
|--------|------|---------|
| 主要 | 想入行的學生 / 新人 | 找到自己的職組方向，了解真實業界 |
| 次要 | 在職從業者 | 找場景、找廠商資源 |
| 公眾 | 一般觀眾 | 了解影視製作現場，去汙名化 |

**核心痛點：** 學生不知道各職組的差異和真實樣貌，網路上的影視知識多數錯誤或過時。

---

## 內容架構（方向一：職組導覽為核心）

### 第一層：職組導覽 Role Explorer（新核心，取代現有知識庫）

每個職組卡片包含：
- 這個職組在幹嘛（30 秒能看完的說明）
- 一天的現場時間軸
- 入行門檻老實說
- 最常見的錯誤認知（去汙名化入口）
- 前輩說一句話（受訪者語錄，有名有姓）

**初期職組範圍：**
- 製片組（首選示範，最多人有概念）
- 攝影組
- 燈光組（現有內容基礎）
- 美術組
- 場記
- 後期剪接

### 第二層：劇組場景庫 Crew Location Database（新核心，取代現有朝聖地圖）

這是「朝陽秘籍數位版」——劇組真正需要的拍攝場景資料，非粉絲打卡地圖。

**場景資料欄位：**
```
地點名稱        → 官方名稱 or 自取暗語名
地址 / GPS      → 精確座標（無名地點用座標）
縣市 / 區域     → 篩選用
視覺標籤        → 霓虹感、工業廢墟、自然空曠、宗教氛圍…
適合拍攝類型    → 電影、MV、廣告、短片
已知拍攝作品    → 片名、品牌廣告
開放時間        → 全天 / 有門禁
申請許可        → 需要 / 不需要 / 未知
停車             → 方便 / 困難 / 路邊
貢獻者備註      → 親身現場感受
```

**種子資料（中部，第一批 8 筆）：**

| 虹揚橋 | 台中西屯 | 霓虹感、城市、美式 | 全天 | 拍過《中部管轄區》Cipher 場景 |
| 小叮噹玩具城 | 台中 | 玩具店、色彩雜亂 | 需確認 | 拍娃娃店首選 |

### 第三層：前輩訪談 Veteran Voices

格式：簡短 Q&A（3-5 題），有照片、名字、年資、職組。
定位：公眾教育的主力內容，去汙名化的窗口。

**問題框架：**
1. 你怎麼入行的？
2. 一個普通工作日長什麼樣子？
3. 你希望自己入行前就知道的事？
4. 外界對這個職組最大的誤解是什麼？
5. 給想入行的學生一句話

### 第四層：現有內容（維持、補強）

- 補助資源：維持現有 8 筆，新增「最後更新日期」和官方來源連結
- 工會資訊：維持現有，新增「何時加入最划算」說明
- Tips：依職組重新分類，從 4 條擴充至各職組各 3-5 條

## Mockup 範圍（提案用）

目標：做出一個能拿去給前輩看、說服他們接受訪談的樣本。

**包含：**
1. 職組導覽入口畫面（8 個職組選擇卡）
2. 製片組完整示範頁（所有欄位填滿，但內容為示範稿）
3. 場景庫示範（以上 8 筆真實場景呈現）
4. 前輩訪談示範（一篇虛構但寫實的樣板）

**不包含：**
- 用戶系統 / 帳號
- 投稿功能
- 付費排名
- 走位圖工具（Phase 2）
- 編劇協作（Phase 3）
- 離線地圖（Phase 3）

## 前輩訪談邀約策略

### 什麼時候去問？

**等這三件事完成再去：**
1. Mockup 做好（他們要看到你認真的程度）
2. 場景庫有 15 筆以上真實資料（讓他們相信平台有料）
3. 有一個可以 demo 的網址（不是 localhost）

預估時機：**Mockup 完成後 2-3 週內**，不要拖超過一個月。

### 邀約草稿

---

平台目前正在累積各職組的真實訪談內容，我想邀請你分享 [職組名稱] 的工作經驗。

我知道你很忙，如果時間不方便，一點都沒關係。但如果這件事對你來說有意義，我會非常感激。
